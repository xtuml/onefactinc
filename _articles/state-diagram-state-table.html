--- title: "State Diagram, State Table" date: 2019-04-10 description: "Two complementary ways to represent the behavior of a finite-state machine in an executable UML model." permalink: /state-diagram-state-table/ source_url: "https://xtuml.github.io/onefactnet/state-diagram-state-table/" --- A state transition diagram is a graphical representation of a finite-state machine in an executable UML model. States appear as rounded boxes, and transitions appear as arrows between them. Events label the transitions; activities can be expressed in action language within states or on transitions. A **state event matrix (SEM)**, also called a state transition table, represents the same information in tabular form. States form the rows, events form the columns, and the cells describe the resulting transitions. The table also makes it possible to specify what happens for state/event combinations that do not cause a transition. An event can be explicitly ignored, or marked as an error with a “Can't Happen” designation. This makes the model's handling of otherwise ambiguous or unexpected events visible. The diagram and table are complementary views of the same state-machine behavior. The diagram emphasizes the flow between states; the table provides a systematic view of every state/event combination.

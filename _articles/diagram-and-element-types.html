--- title: "Diagram and Element Types" date: 2020-04-07 description: "An overview of diagram types supported by BridgePoint for xtUML, UML, and SysML modeling." permalink: /diagram-and-element-types/ source_url: "https://xtuml.github.io/onefactnet/diagram-and-element-types/" thumbnail: "/assets/images/diagram_elements-9630063.gif" --- BridgePoint is a systems modeling tool focused on Shlaer-Mellor xtUML (Executable and Translatable UML). In addition to executable model elements, the tool supports analysis and documentation diagrams. BridgePoint supports the UML diagram types and the SysML diagram types that are part of the common overlap.

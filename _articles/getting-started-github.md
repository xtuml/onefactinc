The BridgePoint source code is published on GitHub under the [xtuml organization](https://github.com/xtuml).

If you are new to Git, it works fundamentally differently from revision-control systems like CVS and SVN. Chief among the differences is that each user has their own clone of the entire repository, rather than a single central repository. GitHub provides the mechanism to publish and share a Git repository.

The One Fact development team primarily used eGit inside Eclipse to interact with Git repositories and GitHub. The model compiler authors found the development flow particularly well suited to using command-line Git tools.

To get started accessing the BridgePoint repositories, create an account on [GitHub](https://github.com).

One Fact created instructional videos for eGit as part of the xtUML Learning Series. The original collection can be found through the [xtUML YouTube channel's GitHub video search](https://www.youtube.com/user/xtUML/search?query=github). The article highlighted these introductory topics:

We like the BeagleBone Black development board.  It is small, fast and runs full Debian Linux.  We jacked it in to our network, ssh’d to it and started development.  gcc is on-board, so we can edit our source with vim and compile on-board.  Anything missing is just an ‘apt install’ command away.

BridgePoint xtUML models translated by the MC-3020 C model compiler run super fast.

--- title: "Stevenson Screen (Weather Station)" date: 2015-09-01 description: "An xtUML model that allocates the functions of a weather station, its sensors, deployment, and MQTT-based communication." permalink: /stevenson-screen-weather-station/ source_url: "https://onefact.net/stevenson-screen-weather-station/" --- This model provides a functional allocation for a weather system built around a [Stevenson screen](https://en.wikipedia.org/wiki/Stevenson_screen). Such a weather enclosure contains and protects instrumentation used to measure temperature, humidity, barometric pressure, and specialized derivatives of these measurements. A *barometer*, *hygrometer*, *thermometer*, *psychrometer*, and *dewcell* measure physical factors in the environment. A *thermograph* records temperature and humidity. Each of these delivers its acquired data through a *concentrator* to an internet *host*. The first diagram shows the “parts” of the system abstracted as UML components. The second diagram illustrates a deployment configuration of the components interconnected across their interfaces. The system uses an interface based on Message Queuing Telemetry Transport (MQTT) message brokering. The host stores recordings in a cloud database. This is a nice example of the *Internet of Things*.

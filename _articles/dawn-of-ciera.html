--- title: "Dawn of Ciera" date: 2020-02-01 description: "Announcing the first production release of Ciera 2.0.0, a Java code generator for BridgePoint and xtUML." permalink: /dawn-of-ciera/ source_url: "https://xtuml.github.io/onefactnet/dawn-of-ciera/" --- The first production release of the Ciera model compiler, version 2.0.0, introduced a general-purpose Java code generator for BridgePoint and xtUML. The original announcement highlighted the following resources: - [Ciera 2.0.0 release notes](https://github.com/xtuml/ciera/releases/tag/v2.0.0) - [Ciera source code](https://github.com/xtuml/ciera) - [Ciera issue tracking](https://support.onefact.net/projects/ciera) - [Ciera user guide and documentation](https://github.com/xtuml/ciera/wiki) - [Ciera user guide PDF](https://xtuml.github.io/cieradoc/userguide/en_US/CieraUserGuide.pdf) - [Feature completeness and metamodel coverage analysis](https://github.com/xtuml/ciera/wiki/11844_Coverage) Ciera was released under the Apache 2.0 license, with release artifacts published to Maven Central. The announcement encouraged users to update their Ciera repositories and move projects from the then-current SNAPSHOT version to 2.0.0. *Historical note: this article documents the February 2020 release. Consult the Ciera repository for current releases and project status.*

Engineering teams model in xtUML using BridgePoint.  Engineering teams model in UML-RT using Papyrus-RT.  A larger system can integrate the generated code from each of these tools together.  An example project has been prepared using the GPS Watch example.

In the GPS Watch, the Tracking component is modeled in xtUML using BridgePoint.  The Heart Rate Monitor capsule is modeled in UML-RT using Papyrus-RT.  Code is generated for both projects and compiled together.

This integrated project will soon be uploaded to a github repository near you.  🙂

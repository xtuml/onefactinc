--- title: "Amazon Web Services (AWS) Lambda" date: 2018-12-19 description: "A demonstration of model-driven generation targeting AWS Lambda, API Gateway, and DynamoDB." permalink: /amazon-web-services-aws-lambda/ source_url: "https://xtuml.github.io/onefactnet/amazon-web-services-aws-lambda/" --- thumbnail: "/assets/images/awslambda-1024x360-4972522.jpeg" Cloud platforms such as Amazon Web Services make it possible to deploy code without provisioning and managing servers directly, scaling from zero to substantial demand. xtUML and BridgePoint support modeling an application independently of its deployment architecture. Code can be generated for embedded targets, cloud environments, or a combination of both. At the time of this article, BridgePoint included capability to generate Java targeting AWS services including **Lambda**, **API Gateway**, and **DynamoDB**. The original post included a [demonstration video](https://www.youtube.com/watch?v=nY984Yev5GI). *Historical note: this article was published in December 2018. AWS services, BridgePoint generators, and deployment practices have changed since then; consult current documentation before applying the example.*
